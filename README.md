## 📌 Description
**GS Notification** est un système de notifications professionnel développé par **GDEV Studio**.  
Ce script offre **150+ types de notifications prédéfinies** et un **système de formatage avancé** pour créer des notifications personnalisées illimitées avec design moderne Tailwind CSS.

---

## ✨ Fonctionnalités
- ✅ **150+ notifications prédéfinies** (Argent, Véhicules, Police, EMS, Justice, Commerce, etc.)
- 🎨 **Notifications custom illimitées** avec icônes Font Awesome et couleurs personnalisées
- 📝 **Système de formatage complet** (gras, italique, couleurs, retours à la ligne, code, etc.)
- ⚙️ **100% configurable** depuis un seul fichier (`config.lua`)
- 🔄 **Vérification automatique** des mises à jour GitHub
- 🚀 **Performance optimisée** - Aucun impact sur les FPS
- 🎯 **2 exports simples** pour une intégration facile
- 📦 **Design moderne** avec animations fluides

---

## 📦 Prérequis
- 🎮 Plateforme : **FiveM**
- 🧩 Framework : **ESX / QBCore / Standalone**
- 📁 Dépendances : **Aucune**
